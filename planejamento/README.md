## Como usar este tutorial

Este material foi escrito como um livro. Cada capítulo traz:

1. **Conceitos** — o que você precisa entender antes de programar
2. **Passo a passo** — o que fazer, na ordem
3. **Código de exemplo** — para adaptar, nunca só copiar sem entender
4. **Exercícios** — para fixar o conteúdo
5. **Checklist e entregáveis** — o que deve estar pronto para avançar

Regras:
- Siga os capítulos **na ordem**.
- Só avance depois de marcar todos os itens `[x]` do capítulo e mostrar os entregáveis ao orientador.
- Anote dúvidas no final de cada notebook, numa célula de texto chamada **"Dúvidas"**.
- Salve tudo na pasta `mudanca_climatica_br/` do Google Drive.
